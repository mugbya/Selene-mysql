# 需求文档

## 编号
sdd-001

## 标题
表显示控制对话框优化

## 背景
用户反馈表显示控制弹窗中的按钮（"全选"、"清除"、"取消"、"保存"）使用文字形式，不够简洁美观。同时存在表总数为0无法加载表数据的问题。

## 需求描述
将表显示控制对话框中的文字按钮替换为相应图标，并优化布局和加载逻辑。

## 详细需求

### 1. 按钮图标化
使用 `div` + 图标实现，禁止使用 `button` 标签。

| 原按钮 | 替换为图标 | 功能 |
|--------|-----------|------|
| 全选 | `CheckSquare` | 选中所有表 |
| 清除 | `XCircle` | 取消选中所有表 |
| 取消 | `X` | 关闭对话框 |
| 保存 | `Save` | 保存设置并关闭 |

### 2. 复选框美化
- 原生 `<input type="checkbox">` 替换为自定义图标方框
- 选中状态显示 `Check` 图标

### 3. 布局重构
- 标题区添加图标 + 描述文字
- 操作栏添加背景色突出显示，统计信息更醒目
- 表列表添加边框容器，选中项有背景色，悬停效果
- 底部按钮简化布局

### 4. 加载逻辑修复
- 添加 `tablesCount` 属性，支持显示表总数（即使表列表未加载完成）
- 添加 `onLoadTables` 回调函数，打开对话框时自动加载表数据
- 当表列表为空但有 tablesCount 时，显示"正在加载表列表..."提示

## 接口变更

### TableVisibilityDialogProps 新增字段
```typescript
interface TableVisibilityDialogProps {
  // ... 原有字段
  tablesCount?: number;      // 表总数（可选）
  onLoadTables?: () => void;  // 加载表数据的回调（可选）
}
```

## 验收标准
1. 所有文字按钮已替换为对应图标（使用 div + 图标）
2. 悬停时显示正确的主题色背景
3. 点击图标后功能与之前文字按钮一致
4. 对话框整体布局美观，无溢出或错位
5. 打开对话框时自动加载表数据（如果未加载）
6. 即使表列表未加载，也能正确显示表总数
